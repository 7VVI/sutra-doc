# 企业知识中台实现方案 2.0

## 基于 RuoYi-Vue-Plus · Compile-First 范式 · 渐进式升级现有 KB 模块

> **核心思想**：在现有 `ruoyi-doc` 模块基础上，以 Karpathy Compile-First 范式为指引，渐进式增加 LLM 编译引擎、向量检索、知识图谱三大能力，将传统文档管理升级为智能知识中台。

```java
@Configuration

public class LlmConfig {

    /**
     * 聊天模型 Bean
```

### 1.3 LLM 调用服务封装

```java
// compile/engine/LlmService.java

@Service
@Slf4j
@RequiredArgsConstructor
public class LlmService {

    private final ChatLanguageModel chatModel;

    /**
     * 调用 LLM 并解析 JSON 响应（带重试）
     *
     * @param prompt      提示词
     * @param resultClass 期望的返回类型
     * @param maxRetries  最大重试次数
     * @return 解析后的结果对象
     */
    public <T> T callAndParse(String prompt, Class<T> resultClass, int maxRetries) {
        for (int attempt = 1; attempt <= maxRetries; attempt++) {
            try {
                String response = chatModel.generate(prompt);
                return JsonUtils.parseObject(response, resultClass);
            } catch (Exception e) {
                log.warn("LLM 调用失败，第 {} 次重试: {}", attempt, e.getMessage());
                if (attempt == maxRetries) {
                    throw new ServiceException("LLM 调用失败，已重试 " + maxRetries + " 次");
                }
                try {
                    Thread.sleep(1000L * attempt);
                } catch (InterruptedException ie) {
                    Thread.currentThread().interrupt();
                    throw new ServiceException("LLM 调用被中断");
                }
            }
        }
        throw new ServiceException("LLM 调用失败");
    }

    /**
     * 简单文本生成（无需 JSON 解析）
     */
    public String generate(String prompt) {
        return chatModel.generate(prompt);
    }
}
```

## Phase 2：文档编译引擎（Compile）

**目标**：将已摄取的文档通过 LLM 编译为结构化知识页面（Wiki），提取实体关系，写入向量库和知识图谱。
**周期**：第 2-3 周
**产出**：上传文档后自动编译，生成知识摘要 + 标签 + 实体，编译吞吐量 ≥ 200 文档/小时

### 核心设计：扩展现有 `asyncProcessDoc()` 流程

现有 `KbDocServiceImpl` 的 `asyncProcessDoc()` 方法在文档上传后异步执行：
1. 解析文档内容（Tika）
2. 写入 ES 索引

**本 Phase 在此流程中追加编译步骤**：

```
上传 → Tika 解析 → [新增] LLM 编译 → ES 索引（增强字段） → [新增] 向量存储
                                                    → [新增] 知识图谱（Phase 4）
```

```java
        KbDoc doc = docMapper.selectById(docId);
        if (doc == null) {
            throw new ServiceException("文档不存在: " + docId);
        }

        // 2. 获取文档解析内容（从 ES 或重新解析）
        String docContent = getDocContent(doc);
        if (StrUtil.isBlank(docContent)) {
            log.warn("文档内容为空，跳过编译: docId={}", docId);
            return null;
        }

        // 3. 超长文档分层处理
        if (docContent.length() > 20000) {
            docContent = summarizeLongDoc(docContent);

        // 4. 构造编译 Prompt

            "folder_path", ObjectUtil.defaultIfBlank(doc.getFolderPath(), "/"),

        CompileResult result = llmService.callAndParse(prompt, CompileResult.class, 3);

        persistCompileResult(docId, result);

        enrichEsDocument(doc, result);
```

```java
// vector/MilvusVectorAdapter.java

@Slf4j
@Component
@RequiredArgsConstructor
@ConditionalOnBean(MilvusServiceClient.class)
public class MilvusVectorAdapter {

    private final MilvusServiceClient milvusClient;
    private final EmbeddingModel embeddingModel;
    private final MilvusProperties properties;

    private static final String COLLECTION_NAME = "kb_wiki_pages";

    /**
     * 初始化 Milvus Collection（应用启动时）
     */
    @PostConstruct
    public void initCollection() {
        if (collectionExists()) {
            return;
        }

        // 创建 Collection
        CreateCollectionParam param = CreateCollectionParam.newBuilder()
            .withCollectionName(COLLECTION_NAME)
            .withDescription("KB 文档向量索引")
            .withShardsNum(2)
            .addFieldType(FieldType.newBuilder()
                .withName("doc_id").withDataType(DataType.Int64).withPrimaryKey(true).build())
            .addFieldType(FieldType.newBuilder()
                .withName("title").withDataType(DataType.VarChar).withMaxLength(500).build())
            .addFieldType(FieldType.newBuilder()
                .withName("summary").withDataType(DataType.VarChar).withMaxLength(2000).build())
            .addFieldType(FieldType.newBuilder()
                .withName("embedding")
                .withDataType(DataType.FloatVector)
                .withDimension(properties.getDimension())
                .build())
            .build();

        milvusClient.createCollection(param);

        // 创建 HNSW 索引
        milvusClient.createIndex(CreateIndexParam.newBuilder()
            .withCollectionName(COLLECTION_NAME)
            .withFieldName("embedding")
            .withIndexType(IndexType.HNSW)
            .withMetricType(MetricType.COSINE)
            .withExtraParam("{\"M\": 16, \"efConstruction\": 200}")
            .build());

        log.info("Milvus Collection '{}' 初始化完成", COLLECTION_NAME);
    }

    /**
     * 向量化并存储文档
     *
     * @param docId  文档 ID
     * @param title  编译后的标题
     * @param summary 编译后的摘要
     */
    public void upsert(Long docId, String title, String summary) {
        // 生成 Embedding
        String textToEmbed = title + "\n" + summary;
        float[] embedding = embeddingModel.embed(textToEmbed).content().vector();

        // 删除旧数据（幂等）
        milvusClient.delete(DeleteParam.newBuilder()
            .withCollectionName(COLLECTION_NAME)
            .withExpr("doc_id == " + docId)
            .build());

        // 插入新向量
        milvusClient.insert(InsertParam.newBuilder()
            .withCollectionName(COLLECTION_NAME)
            .withFields(List.of(
                new InsertParam.Field("doc_id", List.of(docId)),
                new InsertParam.Field("title", List.of(title)),
                new InsertParam.Field("summary", List.of(
                    StrUtil.sub(summary, 0, 1990))),
                new InsertParam.Field("embedding", List.of(toFloatList(embedding)))
            ))
            .build());
    }

    /**
     * 语义搜索
     *
     * @param query 查询文本
     * @param topK  返回条数
     * @return 搜索结果列表
     */
    public List<VectorSearchResult> search(String query, int topK) {
        float[] queryEmbedding = embeddingModel.embed(query).content().vector();

        SearchParam param = SearchParam.newBuilder()
            .withCollectionName(COLLECTION_NAME)
            .withVectors(List.of(toFloatList(queryEmbedding)))
            .withTopK(topK)
            .withMetricType(MetricType.COSINE)
            .withParams("{\"ef\": 100}")
            .withOutFields(List.of("doc_id", "title", "summary"))
            .build();

        R<SearchResults> response = milvusClient.search(param);
        return parseResults(response);
    }

    private boolean collectionExists() {
        R<DescribeCollectionResponse> resp = milvusClient.describeCollection(
            DescribeCollectionParam.newBuilder()
                .withCollectionName(COLLECTION_NAME)
                .build());
        return resp.getStatus() == Status.Success.getCode();
    }

    private List<Float> toFloatList(float[] arr) {
        List<Float> list = new ArrayList<>(arr.length);
        for (float v : arr) { list.add(v); }
        return list;
    }
}
```

```java
// graph/Neo4jGraphAdapter.java

@Slf4j
@Component
@RequiredArgsConstructor
@ConditionalOnProperty(prefix = "knowledge.neo4j", name = "uri")
public class Neo4jGraphAdapter {

    private final Driver neo4jDriver;

    /**
     * 写入实体和关系到知识图谱
     *
     * @param entities 实体列表
     * @param relations 关系列表
     * @param docId 来源文档 ID
     */
    public void writeEntitiesAndRelations(
        List<CompileResult.EntityDto> entities,
        List<CompileResult.RelationDto> relations,
        Long docId
    ) {
        try (Session session = neo4jDriver.session()) {
            // 批量 MERGE 实体节点（幂等）
            session.executeWrite(tx -> {
                for (CompileResult.EntityDto entity : entities) {
                    tx.run("""
                        MERGE (e:Entity {name: $name})
                        ON CREATE SET e.type = $type, e.description = $desc, e.created_at = datetime()
                        ON MATCH  SET e.type = $type, e.description = $desc, e.updated_at = datetime()
                        WITH e
                        MERGE (d:Doc {id: $docId})
                        ON CREATE SET d.created_at = datetime()
                        MERGE (e)-[:MENTIONED_IN]->(d)
                        """,
                        Map.of(
                            "name", entity.getName(),
                            "type", entity.getType(),
                            "desc", entity.getDescription(),
                            "docId", docId
                        )
                    );
                }
                return null;
            });

            // 批量 MERGE 关系边
            session.executeWrite(tx -> {
                for (CompileResult.RelationDto rel : relations) {
                    String relType = sanitizeRelationType(rel.getRelation());
                    tx.run(String.format("""
                        MERGE (a:Entity {name: $from})
                        MERGE (b:Entity {name: $to})
                        MERGE (a)-[r:%s]->(b)
                        ON CREATE SET r.source_doc = $docId, r.created_at = datetime()
                        """, relType),
                        Map.of("from", rel.getFrom(), "to", rel.getTo(), "docId", docId)
                    );
                }
                return null;
            });

            log.info("写入知识图谱: docId={}, entities={}, relations={}",
                docId, entities.size(), relations.size());
        }
    }

    /**
     * 基于实体关系的图谱检索
     * 解决知识孤岛：通过关系链找到语义近但关键词差异大的文档
     *
     * @param entityNames 查询中识别到的实体名列表
     * @param topK 返回条数
     * @return 相关文档 ID 和匹配得分
     */
    public List<GraphSearchResult> searchByEntities(List<String> entityNames, int topK) {
        try (Session session = neo4jDriver.session()) {
            Result result = session.run("""
                MATCH (e:Entity)
                WHERE e.name IN $names
                MATCH (e)-[:MENTIONED_IN]->(d:Doc)
                WITH d, count(e) AS matchCount
                OPTIONAL MATCH (d)-[:RELATED_TO]-(d2:Doc)
                RETURN DISTINCT d.id AS docId, matchCount
                ORDER BY matchCount DESC
                LIMIT $limit
                """,
                Map.of("names", entityNames, "limit", topK)
            );

            return result.list(record -> new GraphSearchResult(
                record.get("docId").asLong(),
                record.get("matchCount").asInt()
            ));
        }
    }

    /**
     * 查找知识孤岛：无关联的文档节点
     */
    public List<Long> findOrphanDocIds() {
        try (Session session = neo4jDriver.session()) {
            Result result = session.run("""
                MATCH (d:Doc)
                WHERE NOT (d)-[:RELATED_TO]-()
                  AND NOT ()-[:MENTIONED_IN]->(d)
                RETURN d.id AS docId
                LIMIT 500
                """);

            return result.list(record -> record.get("docId").asLong());
        }
    }

    /**
     * 获取子图（供前端知识地图可视化）
     *
     * @param centerDocId 中心文档 ID
     * @param depth 扩展深度
     */
    public GraphData getSubgraph(Long centerDocId, int depth) {
        try (Session session = neo4jDriver.session()) {
            Result result = session.run("""
                MATCH path = (d:Doc {id: $docId})-[*1..%d]-(connected)
                RETURN nodes(path) AS nodes, relationships(path) AS rels
                """.formatted(depth),
                Map.of("docId", centerDocId)
            );

            // 解析为前端可视化的节点和边数据
            return parseGraphData(result);
        }
    }

    /** 关系类型白名单（防 Cypher 注入） */
    private String sanitizeRelationType(String relation) {
        return relation.toUpperCase()
            .replaceAll("[^A-Z_]", "_")
            .replaceAll("_+", "_");
    }
}
```

### 5.2 RRF 融合排序器

```java
// query/RrfReranker.java

@Component
@RequiredArgsConstructor
public class RrfReranker {

    private final KnowledgeSearchProperties searchProperties;

    /**
     * RRF (Reciprocal Rank Fusion) 融合排序
     * 将多路检索结果统一为排序分数
     *
     * @param vectorResults 向量检索结果
     * @param esResults ES 全文检索结果
     * @param graphResults 图谱检索结果
     * @param topN 返回前 N 条
     * @return 融合排序后的结果
     */
    public List<RankedResult> fuse(
        List<VectorSearchResult> vectorResults,
        List<KbSearchResultVo> esResults,
        List<GraphSearchResult> graphResults,
        int topN
    ) {
        double vectorWeight = searchProperties.getVectorWeight();     // 0.5
        double fulltextWeight = searchProperties.getFulltextWeight(); // 0.3
        double graphWeight = searchProperties.getGraphWeight();       // 0.2
        int k = searchProperties.getRrfK();                           // 60

        Map<Long, Double> scoreMap = new HashMap<>();
        Map<Long, RankedResult.RankedResultBuilder> builderMap = new HashMap<>();

        // 向量检索贡献
        for (int i = 0; i < vectorResults.size(); i++) {
            Long docId = vectorResults.get(i).getDocId();
            scoreMap.merge(docId, vectorWeight / (k + i + 1), Double::sum);
            builderMap.computeIfAbsent(docId, id -> RankedResult.builder().docId(id))
                .title(vectorResults.get(i).getTitle())
                .hasVectorHit(true);
        }

        // 全文检索贡献
        for (int i = 0; i < esResults.size(); i++) {
            Long docId = esResults.get(i).getDocId();
            scoreMap.merge(docId, fulltextWeight / (k + i + 1), Double::sum);
            builderMap.computeIfAbsent(docId, id -> RankedResult.builder().docId(id))
                .title(esResults.get(i).getDocTitle())
                .hasFulltextHit(true);
        }

        // 图谱检索贡献
        for (int i = 0; i < graphResults.size(); i++) {
            Long docId = graphResults.get(i).getDocId();
            scoreMap.merge(docId, graphWeight / (k + i + 1), Double::sum);
            builderMap.computeIfAbsent(docId, id -> RankedResult.builder().docId(id))
                .hasGraphHit(true);
        }

        // 按 RRF 分数降序
        return scoreMap.entrySet().stream()
            .sorted(Map.Entry.<Long, Double>comparingByValue().reversed())
            .limit(topN)
            .map(e -> builderMap.get(e.getKey())
                .rrfScore(e.getValue())
                .build())
            .collect(Collectors.toList());
    }
}
```

### 6.1 孤岛扫描器

```java
// lint/OrphanPageScanner.java

@Slf4j
@Service
@RequiredArgsConstructor
public class OrphanPageScanner {

    private final Neo4jGraphAdapter graphAdapter;
    private final KbDocMapper docMapper;
    private final LlmService llmService;
    private final PromptTemplateManager promptManager;

    /**
     * 扫描知识孤岛并尝试自动修复
     * 由 SnailJob 定时调度执行
     */
    public LintReport scanAndFix() {
        // 1. 从 Neo4j 查找孤岛文档
        List<Long> orphanDocIds = graphAdapter.findOrphanDocIds();
        log.info("发现 {} 个知识孤岛文档", orphanDocIds.size());

        if (CollUtil.isEmpty(orphanDocIds)) {
            return LintReport.empty();
        }

        // 2. 尝试 LLM 自动修复（每次最多 20 个）
        List<Long> autoFixed = attemptAutoFix(
            orphanDocIds.subList(0, Math.min(20, orphanDocIds.size())));

        // 3. 标记剩余孤岛
        List<Long> needsReview = orphanDocIds.stream()
            .filter(id -> !autoFixed.contains(id))
            .collect(Collectors.toList());

        // 4. 更新数据库标记
        markOrphanStatus(needsReview, true);
        markOrphanStatus(autoFixed, false);

        return LintReport.builder()
            .totalOrphans(orphanDocIds.size())
            .autoFixed(autoFixed.size())
            .pendingReview(needsReview.size())
            .scanTime(LocalDateTime.now())
            .build();
    }

    /**
     * 让 LLM 为孤岛文档找到关联点
     */
    private List<Long> attemptAutoFix(List<Long> orphanDocIds) {
        List<Long> fixed = new ArrayList<>();

        for (Long docId : orphanDocIds) {
            try {
                KbDoc orphan = docMapper.selectById(docId);
                if (orphan == null) continue;

                // 获取所有文档标题作为关联候选
                String prompt = String.format("""
                    以下是一个孤立的知识文档（没有与其他文档的关联）：

                    标题：%s
                    摘要：%s

                    请给出 3-5 个可能的知识标签，以便与相关文档建立关联。
                    输出 JSON 数组，如 ["标签1", "标签2"]，不要解释。
                    """,
                    orphan.getDocTitle(),
                    orphan.getSummary()
                );

                String response = llmService.generate(prompt);
                List<String> suggestedTags = JsonUtils.parseArray(response, String.class);

                if (CollUtil.isNotEmpty(suggestedTags)) {
                    // 用 LLM 建议的标签更新文档标签
                    updateDocTags(docId, suggestedTags);
                    fixed.add(docId);
                    log.info("自动修复孤岛文档: docId={}, suggestedTags={}", docId, suggestedTags);
                }
            } catch (Exception e) {
                log.warn("孤岛自动修复失败: docId={}", docId, e);
            }
        }
        return fixed;
    }
}
```

```java
// lint/StalenessChecker.java

@Slf4j
@Service
@RequiredArgsConstructor
public class StalenessChecker {

    private final KbDocMapper docMapper;
    private final TransactionTemplate transactionTemplate;

    /** 过期阈值：6 个月 */
    private static final int STALE_DAYS = 180;

    /**
     * 检测过期内容并降权
     * 由 SnailJob 每周一执行
     */
    public int checkStaleness() {
        LocalDateTime threshold = LocalDateTime.now().minusDays(STALE_DAYS);

        // 查询超过阈值且未标记过期的已发布文档
        List<KbDoc> staleDocs = docMapper.selectList(
            new LambdaQueryWrapper<KbDoc>()
                .lt(KbDoc::getUpdateTime, threshold)
                .eq(KbDoc::getCompileStatus, CompileStatusEnum.COMPILED.getCode())
        );

        if (CollUtil.isEmpty(staleDocs)) {
            return 0;
        }

        // 批量更新过期标记
        transactionTemplate.executeWithoutResult(status -> {
            for (KbDoc doc : staleDocs) {
                // 添加"待更新"标签，降低质量评分
                // ...
                docMapper.updateById(doc);
            }
        });

        log.info("检测到 {} 个过期知识文档", staleDocs.size());
        return staleDocs.size();
    }
}
```

### 7.1 答案生成器（含 Writeback）

```java
// query/AnswerGenerator.java

@Slf4j
@Service
@RequiredArgsConstructor
public class AnswerGenerator {

    private final HybridSearchOrchestrator searchOrchestrator;
    private final KbDocMapper docMapper;
    private final LlmService llmService;

    /**
     * 基于知识库的智能问答
     * Karpathy 核心原则：新结论写回 Wiki（Writeback is mandatory）
     *
     * @param question 用户问题
     * @return 包含答案和引用来源的响应
     */
    public AnswerResponse answer(String question) {
        long start = System.currentTimeMillis();

        // 1. 混合检索获取相关文档
        List<RankedResult> candidates = searchOrchestrator.search(
            question, HybridSearchOptions.defaults());

        // 2. 加载文档详细内容（取 Top 5）
        List<KbDoc> contextDocs = candidates.stream()
            .limit(5)
            .map(r -> docMapper.selectById(r.getDocId()))
            .filter(Objects::nonNull)
            .collect(Collectors.toList());

        if (CollUtil.isEmpty(contextDocs)) {
            return AnswerResponse.noResult(question);
        }

        // 3. 构造 RAG Prompt
        String context = contextDocs.stream()
            .map(doc -> String.format("## %s\n%s",
                doc.getDocTitle(),
                ObjectUtil.defaultIfBlank(doc.getSummary(), "")))
            .collect(Collectors.joining("\n\n"));

        String prompt = String.format("""
            基于以下知识库内容回答问题。

            ## 相关知识
            %s

            ## 问题
            %s

            ## 要求
            - 仅基于提供的知识库内容作答，不要编造信息
            - 若知识库中没有相关信息，明确说明
            - 回答末尾列出引用来源（文档标题）
            - 若你的回答综合出了原知识库未收录的新结论，用 [NEW_INSIGHT]...[/NEW_INSIGHT] 标签包裹
            """, context, question);

        String rawAnswer = llmService.generate(prompt);

        // 4. 提取新结论，异步写回（Writeback is mandatory）
        extractAndWritebackInsights(rawAnswer, contextDocs);

        long latency = System.currentTimeMillis() - start;
        log.info("问答完成: latency={}ms, sources={}", latency, contextDocs.size());

        return AnswerResponse.builder()
            .answer(cleanAnswer(rawAnswer))
            .sourceDocs(contextDocs.stream()
                .map(d -> new SourceRef(d.getDocId(), d.getDocTitle()))
                .collect(Collectors.toList()))
            .latencyMs(latency)
            .build();
    }

    /**
     * 提取新结论并异步写回知识库
     * Karpathy 核心原则：每次问答产生的新知识必须写回
     */
    @Async
    protected void extractAndWritebackInsights(String rawAnswer, List<KbDoc> sourcedDocs) {
        String pattern = "\\[NEW_INSIGHT\\](.*?)\\[/NEW_INSIGHT\\]";
        Matcher matcher = Pattern.compile(pattern, Pattern.DOTALL).matcher(rawAnswer);

        while (matcher.find()) {
            String insight = matcher.group(1).trim();
            if (StrUtil.isNotBlank(insight)) {
                log.info("检测到新结论，触发写回: {}",
                    StrUtil.sub(insight, 0, 100));
                // 将新结论推入编译队列，作为增量内容补充到相关 Wiki 页面
                // wikiWritebackService.writebackInsight(insight, sourcedDocs);
            }
        }
    }

    private String cleanAnswer(String raw) {
        return raw.replaceAll("\\[NEW_INSIGHT\\].*?\\[/NEW_INSIGHT\\]", "").trim();
    }
}
```

## 附录：关键设计决策

### 为什么不引入 Kafka？

现有项目使用 Redis Stream + Spring Event 作为消息基础设施。10w 文档规模下，Redis Stream 完全够用（消费组、持久化、ACK 机制都具备），避免引入新中间件的运维成本。若后续规模增长到 100w+，再考虑迁移 Kafka。

### 为什么不推翻重建？

现有 `ruoyi-doc` 模块已经实现了文档管理 80% 的基础能力（上传、解析、ES 检索、权限、目录、版本）。2.0 方案的核心是**在现有基础上叠加智能层**，通过扩展 `asyncProcessDoc()` 流程插入编译步骤，通过新增 Controller 暴露新能力，对现有功能零侵入。

### 为什么 MVP 不用 Neo4j？

知识图谱是锦上添花，不是必需品。MVP 阶段 ES 全文 + Milvus 向量的混合检索已经能覆盖 90% 的查询场景。图谱的真正价值在于发现隐含关联（解决知识孤岛），这在 Phase 4 引入即可。

### 为什么用 LangChain4j 而不是 Spring AI？

项目已引入 `spring-ai-alibaba`（用于 Tika 文档解析），但 LLM 编译场景需要更灵活的 Prompt 管理和输出解析。LangChain4j 在这方面的 API 更成熟，且与 Spring AI 可以共存。嵌入模型直接用 LangChain4j 的 `EmbeddingModel` 接口，保持一致性。

### Writeback 为什么是强制的？

这是 Karpathy 思想的核心：**每次问答产生的新结论必须写回知识库**，否则下次相同问题仍要重新推理，系统永远不会"变聪明"。写回机制将系统从"工具"升级为"会学习的知识库"。

### 如何控制 LLM 幻觉？

1. **编译阶段**：低温度（0.1）+ JSON 强制输出格式
2. **查询阶段**：Prompt 中明确限制"仅基于知识库内容"
3. **Lint 阶段**：定期交叉验证同实体不同文档的陈述是否矛盾
4. **质量评分**：信息密度低于阈值（0.5）的文档在检索时降权
5. **Writeback 审核**：新结论写回前可配置人工审核队列
